📊 Controle Financeiro














Projeto simples de sistema de controle financeiro criado com o objetivo de treinar o uso de API e frontend web.

🚀 Sobre

Este projeto é um pequeno site para gerenciar finanças pessoais, permitindo:

adicionar transações

editar registros

visualizar lançamentos

consumir uma API simulada

Foco principal: prática de CRUD com API + JavaScript frontend.

💡 Funcionalidades

💵 Registrar entradas (receitas)

💸 Registrar saídas (despesas)

📈 Visualizar lista de transações

🔄 Integração com API (simulada via JSON)

🧠 Consumo de API com JavaScript

Métodos utilizados:

GET

POST

PUT

DELETE

🧰 Tecnologias Utilizadas
Tecnologia	Uso
HTML	Estrutura do site
CSS	Estilização visual
JavaScript	Lógica e integração com API
JSON Server	API simulada local
📌 Como Usar

Clone o repositório:

git clone https://github.com/PedroGuthDev/Controle_Financeiro.git


Instale as dependências:

npm install json-server


Rode o script para iniciar a API simulada local:

npm run json-server


Abra o index.html no navegador
ou utilize Live Server no VS Code.
