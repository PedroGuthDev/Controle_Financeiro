---

## 🚀 Sobre

Este projeto é um pequeno site para gerenciar finanças pessoais, permitindo:

- Adicionar transações
- Editar registros
- Visualizar lançamentos
- Consumir uma API simulada

**Foco principal:** prática de CRUD com API + JavaScript no frontend.

---

## 💡 Funcionalidades

💵 Registrar entradas (receitas)  
💸 Registrar saídas (despesas)  
📈 Visualizar lista de transações  
🔄 Integração com API simulada  
🧠 Consumo de API com JavaScript

---

## 🔌 Métodos de API Utilizados

- DELETE

## 📌 Como Usar

Clone o repositório:

```bash
git clone https://github.com/PedroGuthDev/Controle_Financeiro.git
```
Instale a dependência da API simulada:
```bash
npm install json-server
```
Inicie a API local:
```bash
npm run json-server
```


Abra o index.html no navegador
ou utilize Live Server no VS Code.
